# Quantized Neural Network Accelerator

A Computer Architecture project comparing INT8 and FP32 neural-network calculations.

The [arithmetic notebook](notebooks/02-quantized-arithmetic.ipynb) includes
explanations, examples, and 13 checks.

To run it, open [Google Colab](https://colab.research.google.com/), select
**File → Upload notebook**, then **Runtime → Run all**. No package installation
is needed.
